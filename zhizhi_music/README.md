**版本**: 1.0.0
**更新日期**: 2026年03月24日
**运行环境**: Android 9.0+，完全离线，无需网络

## 一、产品简介

知知小音乐是专为儿童（3-12岁）设计的**尤克里里+唱歌全能训练助手**，完全离线运行，无广告、无内购、无注册登录。

**核心特色**：
- 离线AI识别：RNNoise降噪 + CREPE音高识别 + 专用和弦模型
- 120首分级曲目（入门40首/中等50首/进阶30首）
- 全程语音朗读，不识字儿童可独立操作
- Material You 设计，护眼配色，适配手机/平板

## 三、快速上手

### 第一步：开始尤克里里练习
1. 打开APP → 点击底部「尤克里里」Tab
2. 点击**开始录音**按钮（红色麦克风）
3. 弹奏你的曲目（5-60秒）
4. 点击**停止录音**
5. 等待8秒内AI分析完成
6. 查看音准/和弦/节奏三维评分和语音指导

### 第二步：唱歌练习
1. 点击底部「唱歌助手」Tab
2. 点击**开始唱歌**，对着手机唱
3. 屏幕实时显示你的音高线
4. 停止后查看评分，语音老师会给出建议

### 第三步：选择曲目练习
1. 点击底部「曲库中心」Tab
2. 按难度筛选（入门/中等/进阶）
3. 点击「示范」听示范音频
4. 点击「练习」进入尤克里里助手对照练习
5. 点击「曲谱」导出PDF打印

## 四、功能详解

### 4.1 AI录音分析（尤克里里助手）

**流程**: 录音 → RNNoise降噪 → Demucs声源分离 → 和弦识别 + CREPE音高识别 → 三维评分

**评分说明**:
- **音准分（35%）**: 每个音的音高准确度，±25音分以内算准
- **和弦分（40%）**: 和弦按法准确度，无闷音、无力道不足
- **节奏分（25%）**: 弹奏节拍与标准BPM的吻合度

**常见提示**:
- 🔴 「闷音」：手指没有按实，需贴近品位按弦
- 🟡 「力道不足」：指尖力度不够，需加强练习
- 🟡 「换和弦慢」：和弦切换有延迟，专项练习切换

### 4.2 节拍器
- 在尤克里里助手顶部开启/关闭
- 默认BPM跟随当前曲目标准速度
- 可用 +/- 按钮手动调节
- 视觉闪烁提示 + 可选声音提示

### 4.3 和弦训练器
- 点击「和弦训练器」按钮，选择要练习的和弦
- 语音朗读每个和弦的详细按法说明
- 支持：C / G / Am / F / Dm / Em / G7

### 4.4 实时音高线（唱歌助手）
- 唱歌时屏幕显示动态音高曲线
- 音高偏高：指示点上移，语音提示「音调偏高，放松喉咙往下走」
- 音高偏低：指示点下移，语音提示「音调偏低，打开口腔往上走」

### 4.5 哼唱识曲
- 点击「哼唱识曲」，哼唱一段旋律（10秒）
- 系统自动识别歌曲并跳转到对应曲目
- 准确率约80%（依赖CREPE模型）

### 4.6 曲谱PDF导出
- 在尤克里里助手或曲库中心均可导出
- 包含：简谱、和弦谱、弹奏要点、难度信息
- 支持保存到手机/打印/分享

### 4.7 成绩单分享
- 练习完成后点击「分享成绩」
- 生成精美成绩海报（含分数、曲目、日期）
- 支持分享到微信、家长群等

## 五、闯关系统

- 入门40首：默认全部开放
- 中等50首：需完成入门曲目解锁
- 进阶30首：需完成中等曲目解锁

**解锁条件**: 在对应关卡曲目中获得 ≥60分 的评分

**勋章体系**:
- 🌟 入门勋章：完成第一首曲目
- 🎵 旋律勋章：连续打卡7天
- 🏆 大师勋章：完成所有进阶曲目

## 七、AI模型说明

所有AI模型在本地离线运行，**不上传任何数据**。

| 模型文件 | 功能 | 大小（参考） |
|----------|------|-------------|
| `rnnoise.tflite` | 深度噪声抑制 | ~200KB |
| `demucs_lite.tflite` | 人声/乐器分离 | ~5MB |
| `crepe.tflite` | 音高识别（半音精度） | ~3MB |
| `chord_ukulele.tflite` | 尤克里里和弦识别 | ~1MB |

> **注意**: 首次使用需将上述模型文件放入 `app/src/main/assets/models/` 目录。
> 无模型时程序自动降级为基础算法（准确率略降），不影响基本功能使用。

## 八、开发构建说明

### 环境要求
- Android Studio Hedgehog (2023.1.1) 或更高
- JDK 17
- Android SDK API 34
- Gradle 8.4

### 构建步骤
```bash
# 1. 克隆项目
git clone <repo>
cd zhizhi_music

# 2. 放入AI模型文件（可选，无模型时降级运行）
# 将 .tflite 文件放入：app/src/main/assets/models/

# 3. 放入音频资源（可选）
# 将 .mp3 音频文件放入：app/src/main/assets/audio/

# 4. 在Android Studio中打开项目
# File → Open → 选择 zhizhi_music 目录

# 5. 编译运行
# Build → Make Project，然后 Run 到设备或模拟器
```

### Debug APK 快速编译
```bash
./gradlew assembleDebug
# APK 位置：app/build/outputs/apk/debug/app-debug.apk
```

### Release APK 编译
```bash
./gradlew assembleRelease
# 需要配置签名 keystore
```

## 十一、常见问题

**Q: 识别不准确怎么办？**
A: 确保录音环境安静，手机麦克风未被遮挡，弹奏时距离手机20-50cm。

**Q: 为什么没有声音提示？**
A: 检查首页「语音朗读」开关是否开启，手机音量是否调高。

**Q: 曲目是锁定状态怎么解锁？**
A: 在曲库中心选择前面难度的曲目练习，评分≥60分即可解锁下一级。

**Q: PDF导出失败？**
A: 检查手机存储权限，确保APP有写入文件的权限。

**Q: 模型文件需要自己提供吗？**
A: 是的，TFLite模型文件需要单独提供。无模型时程序使用内置基础算法，功能可用但精度略低。
